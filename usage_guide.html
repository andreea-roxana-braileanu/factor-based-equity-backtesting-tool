Investment Simulator

A quick guide for anyone using this project

This tool answers one question: if you had invested money in a stock in the past, what would it be worth today? It pulls real historical stock prices and compares your pick against just owning the overall market (the S&P 500), so you can see whether picking that stock was actually a good move.

How to run it

1
Run the file
In PyCharm, right-click interactive_simulator.py and choose Run
2
Answer 3 questions
Type in a stock ticker, an amount of money, and how many years back
3
See the result
A chart is saved to your project folder, and the numbers print in the console
